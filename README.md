# Undergraduate Physics & Astrophysics Reports

This repository contains selected reports and analytical projects completed during my BSc (Hons) in Astrophysics at **Royal Holloway, University of London**. Each report demonstrates practical application of experimental methods, quantitative analysis, and scientific communication.

---

## Contents

### 1. [Spectral Analysis of the Pleiades Cluster](https://github.com/hanaan64/Astrophysics-Reports/blob/main/Spectral%20Analysis%20of%20The%20Pleiades%20Cluster.pdf)
*Performed CCD photometry and data reduction to derive stellar magnitudes, colour indices, and temperature distributions using Python and IRAF-based methods.*

- Tools: **Python, NumPy, Matplotlib**
- Concepts: **Photometry, HR Diagrams, Blackbody fitting**
